# Bento Grids — Troubleshooting & FAQs
*Common questions and what to do when things don't work as expected*

---

## Who can create Bento Grids?

Any workspace member — both Admins and Builders — can create, save, and export Bento Grids.

---

## Does the Bento Grid stay in sync with my Release Notes?

No. Once you save a Bento Grid, it is a snapshot of the content at that point. If you update the Release Notes after saving, the grid does not update automatically — you need to regenerate it. Regenerating runs the AI grouping again on the latest content.

---

## Can I create a Bento Grid without Release Notes?

Yes. The file upload option lets you create a Bento Grid from any content source — a markdown file, a plain text document, or an export from another tool. The result is stored as a standalone grid (not linked to any Release).

---

## The AI grouping doesn't look right. Can I fix it?

Yes. The review step before the grid renders is your chance to adjust the grouping. You can reorder, merge, or split cells. The AI grouping is a starting point — you are always in control of the final layout.

---

## Can I have more than one Bento Grid per Release Note?

Only one saved Bento Grid per Release Note is kept. If you regenerate a grid for the same Release Note, it replaces the previous saved version. To preserve a previous version, export it as PNG or PowerPoint before regenerating.

---

## How many cells can a Bento Grid have?

There is a maximum number of sections (cells) per grid. If your source content has too many distinct items, the AI will group related items together to stay within that limit. This is by design — a grid with too many cells becomes hard to read at a glance.

---

## I don't see the Google Slides export option.

Google Slides upload requires a Google account to be connected. If you haven't connected Google, the option may not appear or will prompt you to authenticate. Contact your workspace admin if you need help with the Google integration.

---

## My Bento Grid was saved but I can't find it.

Open the Bento Grids module from the left-hand navigation. The list shows:
- All Release Notes for your organization that have a saved grid
- Any standalone (file-sourced) grids

If a Release Note appears without a "Saved" indicator, a grid has not been saved for it yet. The entry is shown so you can start creating one.

---

## The PNG export looks blurry or low-resolution.

Try exporting in a larger aspect ratio (16:9 is the widest) and ensuring the grid has loaded fully before exporting. If the issue persists, use the PowerPoint export and save the slide as an image from within PowerPoint or Google Slides for higher resolution output.

---

## Can I edit the grid cells manually?

The review step lets you adjust the grouping before the grid is rendered. After rendering, the content of cells is not directly editable within Lodestone — if you need to change the text, you can either regenerate from updated source content or edit the exported PowerPoint or Google Slides file directly.

---

## Does archiving a Release affect its Bento Grids?

No. Archiving a Release does not delete or archive the Bento Grids associated with its Release Notes. Saved grids remain accessible in the Bento Grids module.
