# Features — How-tos & Workflows
*Step-by-step guides for the most common Feature workflows*

---

## Creating a Feature

### Option A: Directly in the Feature Backlog

The most straightforward way to add a Feature is directly from the backlog.

1. Navigate to the Features module from the left-hand navigation.
2. Click the Add Feature button (or equivalent entry point in the backlog).
3. Enter a Feature Name. This is the only required field — you can save immediately and add more detail later.
4. Optionally add a Description. The more context you provide, the better any AI-generated documents will be.
5. Save the Feature. It now appears in your backlog.

### Option B: From a Roadmap

If you're building out a Roadmap and a new idea comes to mind, you can type it directly into the Roadmap entry field. When you do, Lodestone automatically adds it to the Feature backlog as well. No extra step required.

### Option C: From an Extract

When you accept an Extract — an AI-identified idea surfaced from a meeting transcript — it automatically becomes a Feature. The Feature Name and Description are carried over from the Extract.

> **Tip:** Don't wait until you have full context to create a Feature. Lodestone is designed for ideas to start lightweight and grow richer over time. A name is enough to preserve the signal.

## Editing and Enriching a Feature

To open a Feature's detail view, click its name anywhere it appears in the backlog.

From the Feature Detail page you can:

- Edit the Feature Name and Description
- Update the Feature's Status
- Enter evaluation scores (Value, Effort, or whichever framework your team uses)
- Generate and manage Documents for this Feature

There's no required sequence — enrich a Feature however and whenever it makes sense.

---

## Updating Feature Status

Feature status can be updated in several places:

- From the Feature Backlog — inline status change
- From the Feature Detail page
- From a Release board — drag the Feature card to a new column

Regardless of where you update it, the change propagates everywhere. A status update in a Release is reflected in the backlog, and vice versa.

> **Important:** Status stages are configured globally in Settings. If you need a stage that doesn't exist yet (e.g. "In Review" or "Blocked"), an admin can add it there.

## Scoring and Evaluating Features

Evaluation fields appear on the Feature Detail page. Which fields are shown depends on the evaluation framework configured in Settings.

### Entering scores

1. Open the Feature Detail page by clicking the Feature name.
2. Locate the evaluation section (typically on the right side or below the description).
3. Enter values for each scoring input (e.g. Reach, Impact, Confidence, Effort for RICE).
4. Lodestone calculates the composite score automatically.

Scores appear in the Feature Backlog, where you can sort and compare Features by their evaluation results.

### Changing your evaluation framework

You can switch evaluation frameworks at any time in Settings. This changes which fields are displayed — it doesn't delete previously entered scores or alter what the Feature represents.

## Adding a Feature to a Roadmap

1. Open the Roadmap you want to add the Feature to.
2. In the item entry field, start typing the Feature name.
3. Select it from the dropdown that appears — this links the existing Feature rather than creating a duplicate.
4. Position it in the hierarchy using drag-and-drop nesting.

A Feature can be added to multiple Roadmaps. There is no limit.

---

## Adding a Feature to a Release

1. Open the Release you want to populate.
2. Use the Feature dropdown to select Features from your backlog.
3. Selected Features appear as cards in the Kanban board under their current status column.

Like Roadmaps, Features can belong to multiple Releases simultaneously.

---

## Generating Documents for a Feature

Lodestone can generate a range of written artifacts directly from a Feature. See the Documents module guide for full detail, but the quick workflow is:

1. Open the Feature Detail page.
2. Scroll to or navigate to the Documents section.
3. Choose a document type (e.g. PRD, Opportunity Canvas, User Stories).
4. Click Generate. Lodestone uses the Feature Name, Description, and your Organization Description to produce a first draft.
5. Review and edit the output — all generated content is fully editable.

> **Tip:** The quality of AI-generated documents is directly tied to the richness of your Feature Description. A one-sentence description produces a thin document. A well-written paragraph produces a much more useful draft.

---

## Deleting a Feature

Deleting a Feature is permanent. When a Feature is deleted, it is removed from any Roadmaps, Releases, or Strategies it belonged to. Associated Documents are deleted along with it.

> **Warning:** There is no undo. If you delete a Feature by mistake, you will need to recreate it manually.
