# Goals & Objectives — How-tos & Workflows
*Step-by-step guides for the most common Goals & Objectives workflows*

---

## Creating a Goal

1. Navigate to **Goals & Objectives** from the left-hand navigation.
2. Click **+ New Goal**.
3. Enter a Goal name. This is the only required field.
4. Optionally add a description to provide context for what the Goal represents.
5. Click **Create**. The Goal appears in the list immediately.

Goals are created in a flat list — there is no nesting or hierarchy within the Goals module itself.

---

## Editing a Goal

Goals can be edited inline, directly from the list.

**To edit the name:**
1. Click the Goal's name in the list. It becomes an editable text field.
2. Type your changes.
3. Press Enter or click elsewhere to save.

**To edit the description:**
1. Click the description text (or the "Add description…" placeholder if empty).
2. Type your changes in the text area that appears.
3. Press Enter or click elsewhere to save.

Press Escape at any point to cancel your changes and revert to the previous value.

---

## Viewing Connected Work for a Goal

When a Goal has at least one object, roadmap, release, or strategy connected to it, a chevron icon appears at the left edge of its row.

1. Click the chevron to expand the Goal row.
2. The downstream view opens below the Goal, showing connected work grouped by type: Objects, Roadmaps, Releases, and Strategies.
3. Click any entry to navigate directly to that item.
4. Click the chevron again to collapse.

If no chevron appears, the Goal has no connected work yet. Once you link objects to the Goal (from the Backlog object detail page) or include those objects in a roadmap or release, the chevron will appear.

---

## Deleting a Goal

Deleting a Goal requires a deliberate confirmation because it can affect other objects.

1. Hover over the Goal row to reveal the delete icon (trash can) at the right edge.
2. Click the trash icon. A confirmation dialog appears.
3. The dialog shows the Goal's name and a summary of connected work — any Strategies, Roadmaps, or Releases that include objects linked to this Goal.
4. If the Goal has child objects, the dialog notes how many objects will be **orphaned** — they remain in the Backlog as top-level items rather than being deleted.
5. Confirm deletion. The Goal is permanently removed.

> **Important:** Deleting a Goal does not delete the objects linked to it. Child objects are orphaned — they remain in the Backlog but lose their parent connection. There is no undo.

---

## Linking an Object to a Goal

Goals gain connected work through the Backlog, not the other way around. To link an existing object to a Goal:

1. Open the Backlog and click on the object you want to connect.
2. In the object detail sidebar, find the **Parents** field.
3. Use the search picker to find and select the Goal.
4. The Goal now appears as a parent of that object. The downstream view on the Goal will update to reflect the connection.

See the Backlog how-tos guide for more detail on the Parents field.
