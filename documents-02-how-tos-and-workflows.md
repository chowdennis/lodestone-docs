# Documents — How-tos & Workflows
*Step-by-step guides for the most common Document workflows*

---

## Generating a Document with AI

AI generation is the fastest way to produce a Document. Lodestone uses the Feature Name, Feature Description, and your Organization Description from Settings to produce a structured first draft.

1. Open the Feature Detail page by clicking a Feature name in the backlog.
2. Navigate to the Documents section.
3. Select the document type you want to generate (e.g. Opportunity Canvas, PRD, User Stories).
4. Click Generate.
5. Review the output — all content is fully editable from this point forward.

> **Tip:** The richness of your Feature Description has a direct impact on output quality. A one-sentence description produces a generic draft. A well-written paragraph that explains the problem, the user, and the intended outcome produces a significantly more useful starting point.

---

## Writing a Document Manually

If you prefer to write from scratch rather than generate with AI, you can do that too.

1. Open the Feature Detail page.
2. Navigate to the Documents section.
3. Select the document type.
4. Choose the option to write manually (rather than generate).
5. Write directly into the document editor.

Manual and AI-generated documents are identical once created — both are fully editable going forward.

---

## Editing a Document

All Documents are editable at any time, regardless of how they were created.

1. Open the Feature Detail page.
2. Find the Document you want to edit in the Documents section.
3. Click into the document to open the editor.
4. Make your changes directly.

There is no publish or approval step — edits are saved as you work.

> **Important:** Don't navigate away while a Document is still generating. Lodestone saves the Document as soon as generation completes, but if you leave the page mid-generation, you'll return to a blank document as if the generation never happened. Wait for generation to finish before navigating elsewhere.

---

## Regenerating a Document

If you've updated a Feature Description and want to refresh a Document's content, you can regenerate it.

> **Warning:** Regenerating a Document immediately overwrites the existing content with no warning prompt and no way to recover the previous version. If you've made edits you want to keep, copy them elsewhere before regenerating.

---

## Exporting a Document as PDF

1. Open the Feature Detail page.
2. Find the Document you want to export.
3. Click the Export option and select PDF.
4. The PDF downloads immediately, ready to share.

---

## Exporting an Opportunity Canvas as PowerPoint

The Opportunity Canvas has an additional export option beyond PDF.

1. Open the Feature Detail page.
2. Find the Opportunity Canvas.
3. Click the Export option and select PPT (or PowerPoint).
4. The slide downloads as a single .pptx file.

This is especially useful when you want to include the canvas in a presentation without rebuilding it manually.

---

## Using Documents Across Different Audiences

Different document types are suited to different audiences. A few common patterns:

- **Aligning leadership or stakeholders** → Opportunity Canvas (exported as PDF or PPT)
- **Handing off to engineering** → PRD + User Stories
- **Preparing for QA** → UAT Test Plan
- **Announcing to customers** → Customer Email or Blog Post
- **Supporting a launch** → Social Media Posts (LinkedIn, Twitter, Instagram)

There's no requirement to produce all document types for every Feature — generate what's useful for where the Feature is in its lifecycle.

---

## Documents per Feature

Each Feature supports one Document per type — for example, one PRD, one Opportunity Canvas, one Customer Email, and so on. You cannot create two Customer Emails for the same Feature.

If you need variations of the same document type, the recommended approach is to edit and iterate within the single document rather than maintaining separate copies.
